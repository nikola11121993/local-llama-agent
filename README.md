# Local Llama Agent 🦙

Локальный Windows‑ассистент с экранным персонажем, локальной LLM через Ollama и безопасной автоматизацией повседневных задач.

## Текущее подтверждённое окружение

- Windows
- Python 3.12.10
- NVIDIA RTX 3050 8 GB
- Ollama 0.34.4
- Модель `qwen3:8b`
- `ollama ps`: модель работает на 100% GPU
- PySide6 + requests установлены
- Локальный прототип `C:\LAMA\lama.py` уже запускается, отображает ламу поверх окон и открывает чат с Ollama

## Цель

Сделать постоянно работающего локального помощника, который:

- живёт на рабочем столе как маленькая анимированная лама;
- общается через локальную модель;
- помнит настройки, историю задач и полезный контекст;
- умеет работать с файлами, Excel и SQLite;
- проверяет почту;
- управляет браузером для разрешённых сценариев;
- скачивает ежедневные отчёты;
- проверяет и сверяет данные;
- заносит подтверждённые данные в КОП;
- запускает задачи по расписанию;
- показывает ход выполнения и ошибки;
- требует подтверждение перед опасными или необратимыми действиями.

## Архитектура

```text
src/lama/
├── ui/             # экранная лама, чат, меню, статусы, анимации
├── brain/          # Ollama, промпты, планирование, маршрутизация запросов
├── memory/         # настройки, история, долговременная память
├── tools/          # файлы, Excel, SQLite, Windows-команды
├── automation/     # планировщик, очереди задач, подтверждения, журнал
├── integrations/   # Gmail, браузер, КОП и другие внешние системы
└── core/           # конфиг, логирование, события, общие модели данных
```

## Принцип надёжности

LLM не должна притворяться, что действие выполнено. Реальные действия выполняются отдельными инструментами с проверяемым результатом. Для изменения данных, отправки сообщений, удаления файлов и других рискованных операций используется подтверждение пользователя.
