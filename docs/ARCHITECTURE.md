# Архитектура Local Llama Agent

> КОП = Комбинат общественного питания. Программа учёта называется «Учет доходов».

## Главное правило

Модель принимает решения и объясняет действия, но реальные изменения выполняются только инструментами. Каждый инструмент обязан вернуть проверяемый результат.

## Поток выполнения

```text
Пользователь / расписание
        ↓
      UI
        ↓
 Brain / Planner
        ↓
 Permission Gate
        ↓
 Tool / Integration
        ↓
 Verification
        ↓
 Memory + Audit Log
        ↓
 UI / уведомление
```

## Уровни риска

- **Read** — чтение файлов, писем, отчётов: можно выполнять автоматически после настройки.
- **Write** — изменение локальных данных и программы «Учет доходов»: сначала подтверждение.
- **External write** — отправка почты, публикация, изменение данных на сайтах: обязательное подтверждение, пока отдельно не разрешено.
- **Destructive** — удаление, массовые изменения, системные команды: отдельное подтверждение и журнал.

## Модули

- `ui`: персонаж, чат, индикаторы и подтверждения.
- `brain`: Ollama, контекст, планирование.
- `memory`: SQLite и настройки.
- `tools`: локальные детерминированные операции.
- `automation`: расписание и очереди.
- `integrations`: Gmail, браузер, программа «Учет доходов».
- `core`: конфиг, события, логирование.
